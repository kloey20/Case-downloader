# LawPhil Case Downloader

A simple, self-contained desktop application that allows you to easily search for and download Philippine Supreme Court cases from [lawphil.net](https://lawphil.net) as clean PDF files.

No complex command-line interfaces—just a clean window where you can type a case number and get your PDF.

## 🚀 Features
* **Native Desktop Feel**: Runs as a standard window application (no annoying black terminal boxes).
* **Zero-Hassle Setup**: Automatically installs its own required Python libraries (`flask`, `pywebview`, `selenium`) the very first time you run it.
* **Smart Search**: Enter just the case numbers (e.g., `238659`) and it will automatically format it and find the right case.
* **Direct URL Support**: Got the link already? Paste it directly to bypass the search.

## 📋 Prerequisites
Before running this app, ensure you have the following installed on your computer:
1. **Python 3**: Ensure it is installed and added to your system PATH.
2. **Microsoft Edge**: The app uses Edge in the background to perfectly format and save the PDFs.
