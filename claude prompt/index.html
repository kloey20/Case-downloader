How it reads a case

01 — Fetch

Get the page

A G.R. number is resolved to its LawPhil address; a pasted link is used directly. The page is fetched whole, with Filipino names decoded correctly.

02 — Clean

Strip the website

Scripts, the opinion switcher, and site navigation come off. Everything that is the decision — caption, body, headings, footnotes — stays exactly as published.

03 — Print

Set for paper

The text is retypeset on A4 or Letter with a running G.R. header, then handed to your browser’s “Save as PDF.” Same engine the original script used.
